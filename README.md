# EYP230I-Proyecto-NHANES

## Proyecto NHANES

### Grupo 1: Vicente Alfaro - Cristian Chávez - Isidora Guíñez - Bruno Parra

#### Descripción de archivos:

- #### eda
  - BMX_L.xpt: Dataset con las medidas corporales de los participantes. 
  - BPXO_L.xpt: Dataset con las medidas de presión de los participantes.
  - DEMO_L.xpt: Dataset con las características demográficas de los participantes.
  - TCHOL_L.xpt: Dataset con las medidas de colesterol de los participantes.
  - dic-variables.xlsx: Diccionario con la descripción de las variables de cada dataset.
  - EDA.R: Script de R en el cual se realizó todo el análisis de datos del avance. 
  
- #### informes
  - informe-avance.pdf: Informe con la primera entrega del proyecto, se detalla la pregunta de investigación, el análisis de datos y los modelos propuestos.

#### Reproducibilidad de los resultados.

Se debe ejecutar el archivo EDA.R en la misma carpeta que los dataset para obtener los mismo resultados, plots y tablas que se detallan en el informe.
